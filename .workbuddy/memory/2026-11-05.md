## 角色语句细分（角色设定 → 22 个部位/属性分类）

用户要求：角色不能全用「角色设定」概括，应按眉毛、眼睛、衣服、裤子等细节拆分。

### 做法（两段）
1. **拆行**：`skills/prompt-analyzer/scripts/split_role_stmts.py`
   - `export`：取「角色设定」442 条语句，多行语句按行切成片段（147 条语句 → 676 片段，唯一 621），生成 `/tmp/rolejob/plan.json` + `pieces.jsonl`
   - AI 子代理按 `/tmp/rolejob/spec.md` 给每个片段分部位类（2 批）
   - `apply`：删除被拆原语句 → 插入片段 → 重排该 prompt 全部语句 sort_order（10 递增）
2. **复核**：`ai_classify.py split/apply --from-types "角色设定,综合外貌"`（新增参数）
   - 把混进角色的非角色内容改判出去（光效/配色/镜头/台词/动作/环境/生成指令），274 条中改判 87 条

### 新增 22 个分类（sort_order 23–44，头→脚→随身）

### 踩坑
- `psql -f /tmp/xxx.sql` 在容器内读不到宿主路径 → 改为 `-f -` + `subprocess input=` 走 stdin。
- 拆分脚本初版把"单行语句"也当成新片段插入，导致同 prompt 重复 295 行 → 用 `id > 备份最大id` 且同 prompt 同文本存在旧行的条件删除副本。备份：`pg_dump -t statements --data-only --inserts`。
- dry-run 误触发建类（建类代码在 dry_run 判断之前），需注意。

### 复用
`ai_classify.py` 现支持 `--from-types`（只处理指定源分类）、`--work`（批次目录）、`--insert-after`（新类插入位置）。
