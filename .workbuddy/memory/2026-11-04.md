# 2026-11-04

## 语句分类改为 AI 语义判断（废弃关键词规则）

- 背景：videoprompt 导入的 19430 条语句 `type_id` 全为空（前端徽章显示"未分类"）。最初的 `classify_zh.py` 关键词加权分类被用户否决，要求全部由 AI 逐条判断，分类不贴切时新建分类。
- 做法：`skills/prompt-analyzer/scripts/ai_classify.py`
  - `split`：从 DB 导出未分类 unique 文本（按 `md5(text_zh)` 去重，12835 条），切成 26 批 × 500 条，单条截断 400 字符，写 `/tmp/typejob/batch-XXX.jsonl`
  - 派 26 个 general-purpose 子代理，每个读 `/tmp/typejob/type_spec.md` + 自己那批，输出 `out/batch-XXX.json`（h → 分类名）
  - `apply --dry-run / --write`：汇总 → 建缺失 `statement_types` → 按 `md5(text_zh)` 批量 update `statements.type_id`
- 结果：111948 条语句全部有分类（0 未分类），新增 8 个分类：
  结构标记(24) 参数设置(25) 画面文字(26) 设定图(27) 情绪表情(28) 图像编辑(29) 使用说明(30) 氛围基调(31)
- 分布前五：分镜 2322 / 动作 1187 / 镜头构图 1174 / 参考素材 1102 / 音效台词 1000
- 前端 `StatementItem.vue` 的徽章文字色改为按背景亮度自适应（深色分类用白字），避免新建分类可选深色。
- `backend/app/seed.py` 补齐全部 31 个分类并改为幂等（按 name 存在则跳过）。
- 删除 `classify_zh.py`（关键词方案，已被 AI 方案替代）。

## 复用要点

- psql 走 `docker compose exec -T postgres psql -U promptweb -d promptweb`。
- 大批量语义分类走"批次文件 + 子代理 + 汇总写库"模式，比单模型串行便宜且可并行。
- SQL 批量 update 用 `(values ('hash'::text, id::int), ...) as v(h,t)`，字符串键必须加引号。
